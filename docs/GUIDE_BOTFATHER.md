# Гайд: создание Telegram-бота и мини-аппа (пошагово)

## Шаг 1. Создаём бота у @BotFather
1. В Telegram найдите **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (например, `VDS RPG`) и username, который **обязательно заканчивается на `bot`** (например, `vds_rpg_between_worlds_bot`).
3. BotFather пришлёт **токен** вида `123456789:AA...` — сохраните его, вставьте в `.env` как `BOT_TOKEN`. **Никому не показывайте токен.**
4. Задайте описание и команды:
   - `/setdescription` → «🌑 VDS RPG : Между Мирами — RPG в мини-аппе»
   - `/setcommands` → `start — Начать игру 🎮`, `profile — Мой профиль`, `admin — Админ-панель 🛠`, `help — Помощь`

## Админ-панель для разработчиков
- Укажите Telegram ID админов в `.env`: `ADMIN_IDS=5992994003,1787475400` (через запятую).
- Админы видят в боте команду `/admin`, а в мини-аппе — вкладку «🛠 Админка»: список всех игроков, выдача ресурсов (Тьма, Э Gez, свитки, опыт), просмотр и сброс профиля игрока, рассылка сообщений всем игрокам.
- Проверка прав — только на сервере: `/api/admin/*` валидируют подписанный initData и сверяют ID с `ADMIN_IDS` (не-админ получает 403).

## Шаг 2. Мини-апп подключается через кнопку Web App
Мини-апп открывается **кнопкой с `web_app`** в сообщении бота (наш бот отправляет её по `/start`) и/или **кнопкой-меню** внизу чата:
- У BotFather: `/setmenubutton` → выберите бота → текст `🎮 Играть` и URL `https://bot-vdsrpg-verte82.bothost.tech/app/?mode=fullscreen`
- Или кодом: `setChatMenuButton` (наш бот делает это автоматически при `/start`).

## Шаг 3. Как устроена мини-апп (кратко)
1. В HTML первым подключается скрипт:
   ```html
   <script src="https://telegram.org/js/telegram-web-app.js"></script>
   ```
   После этого доступен `window.Telegram.WebApp`.
2. Приложение читает `Telegram.WebApp.initData` — подписанные данные пользователя (id, имя, `hash`).
3. `initData` отправляется на бэкенд (`POST /api/auth`), где проверяется HMAC-подпись (`secret = HMAC_SHA256("WebAppData", bot_token)`). Только после этого доступно API игры.
4. Бот принимает обновления через **webhook** (`POST /webhook`) — удобно для shared-хостинга, где нельзя держать долгоживущий polling-процесс.

## Шаг 4. Принудительный горизонтальный экран (landscape)
Мини-апп сама запрашивает горизонтальный режим у Telegram:
```js
const tg = window.Telegram.WebApp;
tg.requestFullscreen();      // полноэкранный режим (Bot API 8.0+)
tg.lockOrientation();        // блокировка ориентации мини-аппа (Bot API 8.0+)
tg.lockOrientation("landscape"); // вариант с аргументом — поддерживается в ряде клиентов
// фолбэк: screen.orientation.lock("landscape") в fullscreen WebView Android
```
В fullscreen Telegram показывает **нативный экран «Rotate your device horizontally»**, если устройство в портрете. Если lock не поддержан клиентом, поверх игры показывается наш фолбэк-оверлей «Поверните устройство». Вёрстка адаптирована под landscape (панель вкладок справа, широкая сетка карты).

## Шаг 5. Установка webhook после деплоя
Откройте один раз:
```
https://bot-vdsrpg-verte82.bothost.tech/setup?secret=ВАШ_SETUP_SECRET
```
Это вызовет `setWebhook` (Telegram будет слать обновления на `/webhook`) и зарегистрирует команды бота.

## Шаг 6. Проверка
- Напишите боту `/start` — придёт сообщение с кнопкой **🎮 Открыть VDS RPG**.
- Откройте мини-апп в портретном режиме — Telegram предложит повернуть устройство горизонтально; в landscape откроется игра.
